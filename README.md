# Big4Arts portfolio preview

This branch contains a lightweight, responsive portfolio concept for Big4Arts. It is plain HTML, CSS, and JavaScript, so it can be hosted directly with GitHub Pages without a build process.

## Preview locally

Open `index.html` in a browser or run a simple local web server from the repository folder.

## Included

- Cinematic landing page using the repository’s original behind-the-scenes photograph
- Featured work for The New American Nomads, Bloody Monday, Mandy of the Ages, What’s Behind the Door, and Streaming Tree
- Filterable project gallery
- Service overview, career story, credentials, and calls to action
- Responsive navigation and accessible reduced-motion behavior

## Before publishing

Replace the stylized project panels with approved production stills, add final project/video URLs, confirm the preferred contact destination, and enable GitHub Pages only after the preview is approved.
